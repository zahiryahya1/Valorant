# Project Roadmap

The roadmap is organized around delivering user value while progressively improving the engineering foundation.

---

# Version 0.1 - Data Pipeline Foundation

Status:
In Progress

Goal:

Create a reliable data ingestion and storage pipeline.

## Features

Completed:

- Valorant API integration
- Match extraction
- Data parsing
- PostgreSQL schema

Remaining:

- Raw JSON storage
- API rate limit handling
- Pipeline error handling
- Automated testing improvements

---

# Version 0.2 - Analytics Engine

Status:
Planned

Goal:

Transform raw match data into meaningful player insights.

## Features

- Season aggregation tables
- Act aggregation tables
- Episode aggregation tables
- Agent statistics
- Map statistics
- Weapon statistics
- Highlight metrics

---

# Version 0.3 - Recap Experience

Status:
Planned

Goal:

Create the Spotify Wrapped-style user experience.

## Features

- Player search
- Season selection
- Summary generation
- Visual statistics
- Personalized highlights

---

# Version 0.4 - Production Deployment

Planned

Deploy the application publicly.

- Frontend deployment
